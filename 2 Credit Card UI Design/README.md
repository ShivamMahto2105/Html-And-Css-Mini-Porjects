# 💳 Credit Card UI Design

This is a simple and elegant **Credit Card UI Design** built using **HTML** and **CSS**.  
It visually represents a modern credit card with realistic details like the logo, chip, card number, cardholder name, and validity date.

---

![Credit Card UI Preview](https://github.com/ShivamMahto2105/Html-And-Css-Mini-Porjects/blob/main/Credit%20Card%20UI%20Design/preview.png)

---

## 🛠️ Technologies Used

- **HTML5** — for the structure  
- **CSS3** — for styling and layout  
- **Flexbox** — for alignment and spacing  
- **Google Fonts (Poppins)** — for modern typography  

---

## 🎨 Features

- Clean and realistic credit card look  
- Fully responsive design  
- Smooth layout using Flexbox  
- Simple and minimal styling for easy customization
