# 🔍 Animated Search Box

A simple and stylish animated search box built using HTML and CSS. The search box expands smoothly when the search icon is clicked.

---

## 🚀 Features
- Expandable search input
- Smooth CSS animation
- Clean and modern UI
- No JavaScript required

---

## 🛠️ Tech Used
- HTML
- CSS
- Font Awesome (for icons)

---

## 📂 How It Works
- A hidden checkbox is used to control the state
- Clicking the search icon checks the checkbox
- CSS `:checked` and `~` selector expand the search box
