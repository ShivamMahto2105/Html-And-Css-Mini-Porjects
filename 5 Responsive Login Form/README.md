# Responsive Login Form

A simple and responsive **Login Form UI** created using **HTML and CSS**.  
It includes input fields for email/phone and password with icons, along with login and signup links.

## 🚀 Features
- Clean and simple UI
- Responsive centered layout
- Font Awesome icons
- Hover effects on buttons and links
- Google Fonts (Poppins)

## 🛠️ Technologies Used
- HTML5
- CSS3
- Google Fonts
- Font Awesome

## ▶️ How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.
