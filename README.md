# HTML & CSS Mini Projects

This repository contains small projects built using **HTML and CSS**.  
Each project is stored in a separate folder — like profile cards, login pages, buttons, and more.  
The goal is to practice frontend design and improve HTML & CSS skills through mini, creative projects.
